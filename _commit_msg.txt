refactor: streamline relay account addition flow — interactive login in admin_bot

- admin_bot now handles the full login flow synchronously:
  1. User clicks "添加账号" → inputs phone number
  2. admin_bot creates temporary Telethon client, sends code request
  3. User inputs verification code → admin_bot calls sign_in
  4. If 2FA needed, admin_bot asks for password → sign_in(password)
  5. Only on success, writes to relay DB + notifies idx_bot
- Removed "提交验证码" and "提交二步密码" buttons from relay menu
  (commands /relay_code and /relay_password retained for re-auth of existing accounts)
- Made _conv_end async to properly clean up temporary Telethon clients on cancel/timeout
- Updated all _conv_end callers (conversation.py, handlers.py, callback.py) to await

## 三、上线阻断（必须修）

### 🔴 BLOCKER-1　`storage/r2.py` `base_url` 仍产生非法 URL

HEAD 实际代码：

```python
@property
def base_url(self) -> str:
    return f"{{https://{self._endpoint}}}/{self._bucket}"
```

- 外层双花括号被转义成字面量，返回 `{https://<endpoint>}/<bucket>`；
- upload/download/delete 用 `f"{self.base_url}/{key}"`、list_objects 用 `f"{self.base_url}?{query}"`，**每次 R2 请求 URL 均非法**；
- 影响：R2 云端全量备份与灾难恢复整体静默失效（异常被吞）。提交 3223ebba 只修了 httpx 与部署脚本，未碰此行。
- ✅ 修复：去掉外层双花括号 → `return f"{{https://{self._endpoint}}}/{self._bucket}"`（内部 `{self._endpoint}` / `{self._bucket}` 保留单花括号）。签名 `_sign`、S-8 querystring 已复核正确，改这一行即可。

## 四、已验证正确的关键实现（VERIFIED-OK 亮点）

**安全**

- `config/settings.py` 启动强校验:强制 `RELAY_ENCRYPTION_KEY` 为合法 Fernet(44字符/32字节);拒绝空或默认 `ADMIN_PASSWORD`(CHANGE_ME_NOW);非回环 `ADMIN_WEB_HOST` 时要求密码 `len>=12`;必填令牌/`COCKROACHDB_URL` 校验。
- `admin/__init__.py`:密码 PBKDF2-HMAC-SHA256(拒绝迭代<10000)+ 常量时间比较,兼容明文平滑迁移;登录失败限流(IP级,含 SQLite 持久化);`_get_client_ip` 仅信任回环代理的 XFF,防伪造绕过;CSRF token + `httponly`/`samesite=strict` cookie;`_sanitize_search` 长度限制 + `re.escape` 防 ReDoS。
- `D1Collection` 全参数化,`_validate_identifier` 白名单校验表/列名,`$regex`→`LIKE ESCAPE`,空 `$in`→`FALSE`。
- `cf-workers/index.js`:强制 `SECRET_TOKEN`(未配置直接 503),webhook secret 定长比较防时序;私聊隔离。

**逻辑/健壮性**

- `permission.check_decode_permission`:原子预扣配额(`try_consume_quota`)+ 投递失败 `refund_user_quota` 回滚,解决 TOCTOU 超额;跨天配额重置、等级变更即时同步。
- 本地任务队列:`mark_local_job_dispatched` CAS 认领防多 worker 重复;`reclaim_stale_dispatched` 回收超时;`get_local_unsynced_jobs` SQL 层限定 `status IN (retried/dead/done)`;本地死信重试上限 `max_dead_retry=2`;`update_local_job_status("done")` 失败会重置 `send_ok=False` 触发重试,避免重复投递。
- `dsp_bot` 投递:refuse-blind-send(备份映射缺失不盲发)+ 环形降级 + 原始频道 C3 回退。
- `mon/scheduler`:R100 独立游标全量归档;`message_backups` 去重防重启重复 copy;`stop_on_failure` 保证映射连续;游标仅在"所有 shadow 均成功"时按 `min` 推进,任一失败保持游标下周期重试——严防丢消息。
- `idx_bot` `mycode:detail` 回调 `find_one({code, uploader_id})` 严格越权校验 + 不存在时静默,防 IDOR/探测。
- `run_all.py`:优雅关闭(SIGTERM/SIGINT→stop_event),崩溃自动重启带窗口限流+冷却,`_auto_seed` 失败即退出(不静默带病启动)。

**工程**

- 新增 `tests/` 回归套件 + `.github/workflows/ci.yml` + `pytest.ini` + `requirements-dev.txt`;新增架构/评审文档(`docs/`)与 QA 覆盖报告。
